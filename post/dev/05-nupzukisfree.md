넙죽이의 지도교수님이 특별한 장치를 만들었습니다. **물론 장치가 안전한지 시험하는 것은 넙죽이의 몫이죠!** **NupzukisFree**는 사용자가 직접 게임 지도를 만들고 플레이하며 다른 사용자와 공유할 수 있는 플랫포머 게임 공유 플랫폼입니다.

<img src="{{ "assets/images/dev/5_1.png" | absolute_url }}" alt="image1" class="post" />

넙죽이의 실험실은 조금 특이합니다. 버튼 하나로 **시점이 바뀌는 기능**이 있거든요! 점프로도 뛰어 넘지 못할 것 같은 장애물이라도, 시점에 따라 쉽게 파해할 수 있는 방법이 생기게 됩니다.

<img src="{{ "assets/images/dev/5_2.png" | absolute_url }}" alt="image2" class="post" />

**NupzukisFree**는 시점이 자유롭게 변하며 퍼즐을 해결한다는 간단한 아이디어와, 지도를 만들고 공유하는 시스템을 합쳐 만들었습니다. 지도 제작의 UI는 깔끔한 디자인을 선보였던 **Bouncy ball**의 맵 에디터 기능을 참고하여 만들었습니다. 당장 업데이트 계획은 없으나, 단순한 규칙 덕분에 창의적인 기믹을 가진 블록들이 추가될 여지는 있어 보입니다.

NupzukisFree는 지금 바로 접속하여 플레이할 수 있습니다. 보다 자세한 설명은 [여기][github] github 저장소를 살펴봐주세요!
